# Практическая работа №2

> Создать параллельное приложение, состоящее из 2 процессов, выполняющих обмен информацией через файл, отображаемый в память (файл на диске не создавать!): 1й процесс посылает 2му ОДНО сообщение, 2й процесс его получает и выводит на экран. Для работы с отображаемым в память файлом использовать функции WinAPI (или другой ОС). Продемонстрировать корректную работу обмена при различных скоростях работы процессов.
